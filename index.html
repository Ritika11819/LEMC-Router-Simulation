How Routers Implement LEMC: Architecture & Mathematical Formulation

Theoretical and deployment principles for college presentation and project evaluation

1. Chained ML Prediction Pipeline

Standard static routing protocols (e.g., OSPF, RIP, BGP) evaluate only static link weights or hop counts. LEMC uses a 3-stage predictive pipeline:

  • Stage 1 (Traffic Demand): Forecasts future traffic surges from active user counts, uplink/downlink ratios, and temporal factors.
  • Stage 2 (Congestion Index): Predicts buffer saturation and link strain chained with predicted traffic volume.
  • Stage 3 (Energy Consumption): Predicts future kilowatt-hour (kWh) power draw and operational hardware stress.

2. Composite LEMC Index Formulation

To eliminate unit disparity between traffic (Mbps) and energy (kWh), both features are min-max normalized across all candidate next-hop paths:

LEMC_i = 0.50 × T_norm(i) + 0.50 × E_norm(i)
Path* = argmin(LEMC_i)

The router's Forwarding Information Base (FIB) dynamically selects the path minimizing this cost function.

3. Production SDN / OpenFlow Integration

In modern 5G core and software-defined networks (SDN):

  • In-band Network Telemetry (INT): Intermediate switches periodically send the 7 telemetry metrics to the SDN controller.
  • Inference at Edge Controller: The ML model predicts future states before congestion queues can form.
  • Proactive Flow Rules: OpenFlow / P4 flow rules update next-hop ports preemptively, preventing packet drops.
